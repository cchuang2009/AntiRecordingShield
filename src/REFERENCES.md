# Technical references

Official Android documentation consulted as implementation references (check current platform behavior before publishing):

- Wi-Fi scan overview: https://developer.android.com/develop/connectivity/wifi/wifi-scan
- Wi-Fi permissions: https://developer.android.com/develop/connectivity/wifi/wifi-permissions
- Bluetooth permissions: https://developer.android.com/develop/connectivity/bluetooth/bt-permissions
- Find BLE devices: https://developer.android.com/develop/connectivity/bluetooth/ble/find-ble-devices
- Runtime permissions: https://developer.android.com/training/permissions/requesting
- Storage Access Framework / create document: https://developer.android.com/training/data-storage/shared/documents-files#create-file
- AudioRecord API: https://developer.android.com/reference/android/media/AudioRecord

## Scope note
These links describe Android APIs and platform constraints. They do not establish that any scanner can detect hidden recording devices. This app deliberately makes no such claim.
